本地考试后端管理系统

基于本地考试机前端镜像的轻量级、无数据库考试管理平台。支持多科目考试生命周期、模拟/标准模式、多人多机考试机客户端。

核心能力

考生、试题、考试、科目统一管理；以考试为单位组织试题和考生。

无数据库明文 JSON本地部署

考试生命周期

创建考试 → 添加科目/试题 → 分配考生 → 准备考试 → 开始考试 → 自动收卷 → 下一科目引导 → 考试结束。

后端权威计时

系统模式

模拟模式支持多场并发、自由登录；标准模式由后台统一开考信号控制。

模拟模式标准模式

考试机客户端

支持多台机器同时登录，准考证号独立匹配，答题记录按考生隔离。

右侧答题卡后端倒计时

快速开始

# 安装后启动
python exam_backend.py server --port 8000

# 管理后台
http://localhost:8000/admin

# 考试机客户端
http://localhost:8000/exam-client

# 导入示例数据
python exam_backend.py seed-demo

目录

  • exam_backend.py：后端、管理 API、管理后台、CLI
  • exam_client.html：可交付考试机客户端
  • mirror/：本地考试机前端镜像资源
  • docs/：GitHub Pages 静态站点

说明

本项目为本地考试系统后端实现，无数据库、无外部服务依赖。GitHub Pages 仅用于项目说明文档展示；实际考试运行需在本机或内网启动 Python 后端。
